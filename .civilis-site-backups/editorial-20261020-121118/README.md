# Civilis Website

Стартовый официальный сайт Minecraft-мода Civilis на **Astro 7 + Starlight**.

## Быстрый старт (Windows / PowerShell)

```powershell
cd civilis-site
npm install
npm run dev
```

Обычно локальная страница: `http://localhost:4321`.

## Импорт полной истории версий

Расположи папки рядом:

```
X:/Dev/civilis/
X:/Dev/civilis-site/
```

Затем в `civilis-site`:

```powershell
npm run sync:changelog -- "X:/Dev/civilis"
npm run build
```

Скрипт читает **только** `CHANGELOG.md` и генерирует `src/content/docs/changelog.md`.
Он не записывает ничего в исходный репозиторий мода. Запускать после обновления changelog.

## Структура

- `src/content/docs/index.mdx` — главная презентационная страница.
- `src/content/docs/mechanics/` — публичное описание механик.
- `src/content/docs/changelog.md` — история версий.
- `src/content/docs/roadmap.md` — короткий публичный roadmap.
- `src/styles/custom.css` — фирменная тема.
- `astro.config.mjs` — навигация и локализация.

## Публикация

Удобный вариант — **отдельный публичный репозиторий `civilis-site`** на GitHub, с размещением через Vercel. Vercel собирает статический Astro-проект стандартной командой `npm run build`. Папка вывода — `dist`.

В основном репозитории Civilis сейчас приватные исходники: публикация сайта не должна раскрывать не предназначенные для посетителей данные. В частности, **не импортируй напрямую огромный внутренний ROADMAP.md или прочие технические файлы**.

В текущем `CHANGELOG.md` могут быть ссылки на коммиты приватного репозитория. Публичные посетители не смогут их открыть до изменения настроек доступа. Перед релизом проверь такие ссылки, тексты патчей и доступность скачивания.

## Особенности стартового проекта

- Русский интерфейс и материалы.
- Разделы: описание, установка, механики, roadmap, changelog.
- Содержимое страниц сгенерировано как стартовая редакция; актуальные условия и доступность функций сверяй с реальными релизами.
- **Автоматическая синхронизация после каждого коммита ещё не настроена**. Пока обновление changelog — ручная команда.

## Примечание к проверке

Архив содержит исходники сайта, не `node_modules` и не готовый билд: среда подготовки не имела доступа к npm registry. Установить зависимости и проверить `astro build` нужно на компьютере с интернетом.
