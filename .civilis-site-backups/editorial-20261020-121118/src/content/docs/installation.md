## Поддерживаемая основа

| Компонент | Требование |
| --- | --- |
| Игра | Minecraft Java Edition **26.2** |
| Загрузчик | Fabric Loader |
| API | Совместимая версия Fabric API для 26.2 |
| Статус | Активная разработка; экспериментальные версии |

:::caution[Загрузка]
У сайта пока нет подтверждённой публичной ссылки на готовую сборку Civilis. Номер коммита или внутреннего патча — не обещание проверенного релиза. Не скачивай JAR со случайных сторонних сайтов.
:::

## Установка, когда сборка опубликована

1. Установи Minecraft Java Edition версии 26.2 и соответствующий Fabric Loader.
2. Установи совместимый Fabric API.
3. Добавь официальный `civilis-…jar` в папку `mods` своего профиля Minecraft.
4. Запусти игру с профилем Fabric и открой обычный мир с натуральной деревней.

Мод рассчитан на взаимодействие с уже существующим миром. Подробнее — [первая деревня](/guide/first-village/).

## Для разработчиков

В исходном проекте используется **Java 25**; сборка проверяется Gradle. Из одного лишь сообщения `BUILD SUCCESSFUL` нельзя сделать вывод, что все игровые сценарии прошли приёмку. Подробности есть в [хронологии](/milestones/) и [истории изменений](/changelog/).

[Репозиторий Civilis](https://github.com/keyready/civilis) сейчас может быть закрыт для посетителей. Публичная страница загрузок появится после выпуска релиза.
