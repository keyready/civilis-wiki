В Civilis город работает не за счёт абстрактной «производительности», а благодаря жителям, выполняющим конкретные поручения.

| Профессия | Роль |
| --- | --- |
| Первопроходец | Запускает инфраструктуру молодой деревни |
| Лесоруб | Заготавливает деревья и работает с посадками |
| Фермер | Готовит грядки, сажает и собирает урожай |
| Строитель | Размещает реальные блоки и развивает инфраструктуру |
| Курьер | Перевозит материалы между местами работы и складами |
| Мастер-крафтер | Изготавливает необходимые предметы и инструменты |
| Сборщик | Собирает предметы, оказавшиеся на земле |
| Шахтёр | Участвует в физической разработке карьера |

Это обзор, а не обещание полной готовности всех рабочих циклов. Актуальные возможности и ограничения фиксируются в [changelog](/changelog/).
