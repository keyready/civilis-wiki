## Совместимость

- **Игра:** Minecraft Java Edition 26.2.
- **Загрузчик:** Fabric.
- **Стадия:** активная разработка.

:::caution[Сборки]
На момент подготовки сайта здесь нет опубликованного стабильного дистрибутива. Не путай внутренние номера сборок с проверенными публичными релизами.
:::

## Как установить мод

1. Установи совместимую версию Minecraft Java Edition и Fabric Loader.
2. Получи JAR официальной сборки Civilis после её публикации.
3. Помести JAR в папку `mods` игры вместе с требуемой Fabric API.
4. Запусти игру с профилем Fabric.

Точная ссылка на загрузку будет добавлена после публикации релиза. Для разработчиков доступна информация в [репозитории проекта](https://github.com/keyready/civilis) (в данный момент доступ к нему может быть ограничен).
