Профессия в Civilis — не название над головой. За ней стоит **конкретная работа**: добраться до места, взять материалы, выполнить задачу и вернуться. При этом жители остаются обычными ванильными NPC.

## Кто за что отвечает

| Роль Civilis | Что делает |
| --- | --- |
| **Первопроходец** | Запускает инфраструктуру новой деревни, добывает первую древесину и помогает создать стартовые хранилища |
| **Лесоруб** | Ищет природные деревья, рубит брёвна, работает с листвой и посадками |
| **Фермер** | Вспахивает землю рядом с водой, сажает семена, собирает урожай, возвращает инструменты |
| **Строитель** | Переносит материалы и физически ставит блоки складов, загонов, кроватей и инженерных объектов |
| **Курьер** | Перевозит грузы между сундуками, складами, рабочими местами |
| **Мастер-крафтер** | Изготавливает инструменты и материалы на настоящем верстаке |
| **Сборщик** | Подбирает настоящие выпавшие предметы и доставляет их в хозяйство |
| **Животновод** | Водит животных в загоны, кормит и размножает поголовье |
| **Разносчик хлеба** | Использует зерно и хлеб для обеспечения жителей едой |
| **Шахтёр** | Ведёт послойную добычу, работает с киркой и вывозит добытый груз |
| **Работник по благоустройству** | Участвует в отдельных задачах расчистки территории |
| **Мясник** | В определённых условиях помогает получить физические материалы для нужд поселения |

Не все профессии нужны постоянно. Пока нет карьера, шахтёрам нечего копать; пока не построен загон, пастуху некуда вести овец.

## Когда всё упирается в один топор

Представь, что у деревни нет топора:

1. Лесоруб с допустимым маршрутом может заняться **аварийной рубкой руками**.
2. Собранные брёвна становятся физическим материалом.
3. Мастер получает заказ и превращает материалы в инструмент.
4. Работнику выдают настоящую вещь, которая расходует прочность.
5. Дальше лесозаготовка ускоряется и начинает снабжать строителей.

Если на любом шаге что-то пошло не так, весь следующий заказ может ждать.

## Смерть работника — не конец проекта

Задачи хранятся за городом или конкретным проектом, а не существуют только в памяти назначенного жителя. Если пастух погиб по дороге или курьер не довёз груз, город может передать заказ другому жителю. Но предметы при этом не восстанавливаются волшебным образом: то, что было в инвентаре, остаётся частью мира.

## Внешний вид

В серии 0.5.22 появились рабочие костюмы для 11 ролей и объёмные аксессуары. Например, у шахтёра есть каска с налобным фонарём, у строителя — пояс с инструментами, у курьера — большой жёлтый рюкзак. Это в первую очередь **визуальный слой**, не дополнительные игровые способности.
