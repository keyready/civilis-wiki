Civilis разрабатывается для **Minecraft Java Edition 26.2** с загрузчиком **Fabric**.

| Что нужно | Версия |
| --- | --- |
| Minecraft | 26.2 |
| Fabric Loader | Совместимый с 26.2 |
| Fabric API | Для Minecraft 26.2 |

:::note[Пока в разработке]
Публичной страницы с готовыми сборками пока нет. Не скачивай JAR с посторонних сайтов: мы ещё не открыли официальный канал распространения.
:::

## Как установить опубликованную сборку

1. Запусти Minecraft 26.2 через Fabric Loader.
2. Добавь подходящий Fabric API.
3. Положи файл `civilis-*.jar` в папку `mods`.
4. Зайди в мир с обычной сгенерированной деревней.

За первой деревней — в [руководство](/guide/first-village/).

## Где следить за выпуском

Все изменения собираются в [истории версий](/changelog/). Там есть и крупные обновления, и небольшие патчи. Исходный [репозиторий Civilis](https://github.com/keyready/civilis) пока закрыт для публичного просмотра.
