Civilis предназначен для **Minecraft Java Edition 26.2** с загрузчиком **Fabric**.

## Что понадобится

| Компонент | Требование |
| --- | --- |
| Minecraft Java Edition | **26.2** |
| Fabric Loader | Версия, совместимая с Minecraft 26.2 |
| Fabric API | Сборка для Minecraft 26.2 |
| Civilis | Совместимый файл `.jar` |

:::note[О доступности]
Civilis ещё разрабатывается. Отдельной публичной страницы с готовыми стабильными сборками пока нет. Не скачивай мод с неизвестных сайтов.
:::

## Когда у тебя есть файл мода

1. Установи Fabric для Minecraft 26.2.
2. Скачай подходящий Fabric API и добавь его в папку `mods`.
3. Положи туда же файл `civilis-<version>.jar`.
4. Запусти Minecraft с профилем Fabric.
5. Зайди в мир и найди природную деревню.

Проверить версию установленного мода можно командой `/civilis version`.

После установки открой [руководство по началу игры](/guide/first-village/). А изменения между версиями собраны в [истории обновлений](/changelog/).
