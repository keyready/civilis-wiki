**Деревня работает сама.** Команды нужны, когда хочется узнать, чем заняты жители, посмотреть план стройки или понять причину остановки. Некоторые действия требуют прав на управление миром.

## Город

| Команда | Назначение |
| --- | --- |
| `/civilis version` | Версия установленного Civilis |
| `/civilis list` | Список зарегистрированных городов |
| `/civilis rescan` | Повторное обследование ближайшей деревни |
| `/civilis work list` | Рабочие задания и их исполнители |
| `/civilis status` | Сохранённое состояние города |
| `/civilis name <название>` | Имя города |
| `/civilis projects status` | Состояние городских проектов и причины ожидания |
| `/civilis projects next` | Следующие физически исполнимые шаги |
| `/civilis info show` | Показать информационную панель |
| `/civilis info hide` | Скрыть панель для себя |

## Пространственная карта

| Команда | Назначение |
| --- | --- |
| `/civilis spatial status` | Состояние планирования |
| `/civilis spatial scan` | Повторно обследовать территорию |
| `/civilis spatial overlay show` | Показать временную цветную разметку |
| `/civilis spatial overlay refresh` | Обновить её после изменений |
| `/civilis spatial overlay clear` | Убрать разметку |

:::caution[Разметка шерстью]
Пространственная карта версии 0.4 использует **реальные временные блоки шерсти** над землёй. После осмотра используй `overlay clear`, иначе они могут влиять на heightmap и проверки территории. Это не то же самое, что клиентская прозрачная голограмма стены.
:::

## Карьер

| Команда | Назначение |
| --- | --- |
| `/civilis quarry status` | Рабочие, слой, прогресс, риски, причины остановки |
| `/civilis quarry preview` | Предпросмотр геометрии карьера |
| `/civilis quarry preview real` | Предпросмотр на фактической глубине; удобнее в spectator |

Есть и служебные команды `reserve`, `release`, `clear` и `testmap`. Это **инструменты разработки**, а не способ нормально запустить добычу; они могут изменить состояние проекта или мира.

## Городская стена

| Команда | Назначение |
| --- | --- |
| `/civilis wall status` | Рассчитать контур и показать причины отказа |
| `/civilis wall preview show` | Клиентский объёмный предпросмотр |
| `/civilis wall preview refresh` | Пересчитать контур |
| `/civilis wall preview clear` | Скрыть голограмму |

Предпросмотр стены **ничего не строит** и не выделяет материалы.

## Загрузка чанков

Команды `/civilis forceload`, `/civilis forceload status`, `/civilis forceload remove` управляют принудительной загрузкой известных чанков города (когда это разрешено в сборке). Это опциональный режим, который может дополнительно нагружать сервер, а не обязательная настройка для Civilis.

Подробнее: [поиск неисправностей](/guide/troubleshooting/).
