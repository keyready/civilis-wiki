**Для обычной игры команды почти не нужны.** Деревня запускается сама. Но с ними удобнее понять, что делают жители и почему стройка ждёт.

Некоторые команды требуют прав оператора или разрешённых читов.

## Основные команды

| Команда | Для чего |
| --- | --- |
| `/civilis version` | Узнать версию установленного мода |
| `/civilis status` | Посмотреть состояние ближайшего города |
| `/civilis list` | Увидеть все зарегистрированные города |
| `/civilis work list` | Посмотреть текущие задания жителей |
| `/civilis projects status` | Узнать, какие большие работы идут или чего им не хватает |
| `/civilis projects next` | Посмотреть ближайшие задачи города |
| `/civilis rescan` | Повторить поиск и обследование деревни |
| `/civilis name <название>` | Переименовать ближайший город |
| `/civilis info show` | Показать информационную панель |
| `/civilis info hide` | Скрыть информационную панель |

## Карта и территория

| Команда | Для чего |
| --- | --- |
| `/civilis spatial status` | Состояние планирования территории |
| `/civilis spatial scan` | Повторное обследование |
| `/civilis spatial overlay show` | Показать разметку участков |
| `/civilis spatial overlay clear` | Убрать разметку |
| `/civilis spatial overlay refresh` | Обновить разметку |

:::caution[Цветная разметка]
Для карты участков используются **временные блоки шерсти**. После просмотра их лучше убрать командой `overlay clear`. Это отличается от прозрачного предпросмотра городской стены, который блоки не меняет.
:::

## Карьер

| Команда | Для чего |
| --- | --- |
| `/civilis quarry status` | Состояние карьера, рабочих, спуска и добычи |
| `/civilis quarry preview` | Посмотреть будущую форму карьера |
| `/civilis quarry preview real` | Посмотреть разметку на глубине |

## Городская стена

| Команда | Для чего |
| --- | --- |
| `/civilis wall status` | Проверить предварительный проект стены |
| `/civilis wall preview show` | Показать будущий контур |
| `/civilis wall preview refresh` | Обновить его |
| `/civilis wall preview clear` | Скрыть |

**Предпросмотр стены не строит блоки**. Это только способ увидеть проект.

Есть и специальные команды для проверки и изменения состояния карьера или принудительной загрузки чанков. Для первого знакомства с модом они не нужны: при неосторожном использовании можно изменить проект или увеличить нагрузку на мир.
